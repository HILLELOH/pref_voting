How this works

This app runs entirely locally using a built-in language model to generate compromise sentences. No API key or internet connection required after setup.

BUILT-IN Llama 3.2 · 1B · Q4_K_M

The model file (Llama-3.2-1B-Instruct-Q4_K_M.gguf, ~700 MB) must be placed in models/ before the first run. 

hf download bartowski/Llama-3.2-1B-Instruct-GGUF \
    Llama-3.2-1B-Instruct-Q4_K_M.gguf \
    --local-dir models/
⏱ Each run takes 3–10 minutes depending on the number of agents and iterations. A live progress display will show what the algorithm is doing.

Coalition Formation Demo

Given agents with differing policy positions, this algorithm finds a majority coalition that agrees on an AI-generated compromise. Read the paper

How it works: Each agent has an ideal policy sentence. Starting from a status quo, the algorithm iterates: (1) agents vote yes if the current proposal is closer to their ideal than the status quo (measured by cosine dissimilarity of sentence embeddings); (2) if a majority coalition is reached, the proposal wins; (3) otherwise, two agents are selected and an LLM generates a compromise sentence as the next proposal. The algorithm guarantees that every agent in the winning coalition genuinely prefers the result over the status quo.
